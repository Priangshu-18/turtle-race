# Turtle Race

A Python simulation of a turtle racing game using the `turtle` graphics module.

## How It Works

- Six turtles of different colours race across the screen
- Player bets on which turtle will win before the race starts
- Each turtle moves a random distance per turn
- Displays win/loss result at the end

## Tech Stack

Python, `turtle` module

## Run

```bash
python turtle_race.py
```
